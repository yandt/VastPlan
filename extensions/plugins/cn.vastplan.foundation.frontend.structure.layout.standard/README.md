# Standard Portal Layout

本基础插件只负责标准 Shell 组合模型的视觉布局：LOGO 放置、图标主轨、常驻二级导航、页头与正文的尺寸、间距、背景和响应方式。

它是可独立签名和按需下载的 `standard` Shell Library，不定义 Slot 名称、不接受功能插件创建页面骨架，也不决定业务组件所在区域；这些职责属于 `ui.structure.shell` Catalog 的稳定语义骨架。

桌面默认采用 64px 图标主轨 + 240px 常驻导航栏。一级图标切换根分组后，二级导航面板完成切换即主动进入顺序上的第一个叶子页面；纯分组不会触发空路由。面板使用共享 `PortalNavigationMenu` 的内联模式：根直属页面、可多开的子分组和三级页面与顶部弹层使用同一菜单行、图标、选中、悬停和无障碍语义，区别仅为常驻排布与展开状态（后者只保存在当前浏览器会话）。页面才触发路由，导航面板不是弹出层。主轨中段依次显示主要、辅助和系统管理分组，系统管理始终为最后一个业务一级入口；尾段只保留固定的账户头像及扩展 Slot。主轨中段、尾段和导航栏各自管理纵向溢出，图标轨支持 Up/Down/Home/End，ArrowRight 进入面板、ArrowLeft 返回。手机隐藏桌面双栏并使用设计系统 Drawer。

Page Header 位于 Page Body 滚动容器之外。布局区域采用“有实际内容才渲染”的统一规则：Slot 贡献、导航分组以及布局自身放置的 LOGO、页面标题等都属于实际内容。完全为空的 Shell Header、Page Aside 和 Footer 会自动折叠；包含页面标题的 Page Header 不会因扩展 Slot 为空而消失。
