# Ant Design 图标目录

- npm 包：`@ant-design/icons-svg`
- 锁定版本：`4.5.0`
- 许可证：MIT
- 上游：<https://github.com/ant-design/ant-design-icons>
- 图标数量：846（Outlined 447、Filled 249、TwoTone 150）

VastPlan 不复制 Iconfont 网站资源。构建输入来自 pnpm 锁定并校验完整性的 MIT npm 包；生成器只生成目录、语义映射和 27 个确定性分片入口，SVG 数据仍由依赖包提供。功能插件只能使用稳定的 `SemanticIconName`，原始目录名称仅供 Foundation UI、图标浏览器和未来语义提升工具使用。
