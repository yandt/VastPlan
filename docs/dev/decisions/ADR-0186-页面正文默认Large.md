# ADR-0186 页面正文默认使用 Large

## 状态

已接受，2026-08-02。

## 背景

ADR-0183 将页面省略 `bodyLayout` 的行为定义为 `fluid`。这保证了升级时布局不变，但也使绝大多数管理页面在宽屏上无限扩展，阅读距离、表单对齐和摘要信息密度缺少统一上限。逐页补充 `bodyLayout: large` 会形成重复配置，并让新增页面容易遗漏标准。

## 决策

1. 页面未声明 `bodyLayout` 时，由统一 Page Body Recipe 按 `large` 处理，最大宽度为 1280px，并由 Shell 居中。
2. 标准侧栏与顶部导航 Shell 必须消费同一解析函数，并把实际默认语义标记为 `data-page-body-layout="large"`。
3. 页面需要横向数据工作区时可以显式声明 `fluid`；`medium`、`small` 与显式 `large` 的行为不变。
4. 不批量向业务页面写入 `large`，默认值只在组合根解释一次。
5. Shell 模板级 `contained` 继续作为平台上限；页面和模板同时限制时仍取更窄值。

## 结果

- 现有未声明宽度的页面自动获得统一的 1280px 正文上限。
- 新页面无需重复配置即可遵循相同视觉标准。
- 大型表格、画布或监控页面仍能通过显式 `fluid` 使用完整可用宽度。
- 本 ADR 只修订 ADR-0183 的默认值，不改变其封闭语义集合、Shell 所有权和禁止任意 CSS 宽度的其他决策。
