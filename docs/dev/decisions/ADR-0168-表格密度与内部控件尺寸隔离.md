# ADR-0168：表格密度与内部控件尺寸隔离

- 状态：已接受
- 日期：2026-07-28
- 修订：[ADR-0167](ADR-0167-三级组件尺寸与组合密度投影.md) 第 2 条

## 背景

将 Collection density 直接投影为所有内部组件的 `sm/md/lg` 后，切换表格密度会同时改变筛选输入、工具栏、分页、卡片、行操作按钮和图标。用户原本只想控制数据表的视觉密度，却得到整页缩放，且行操作图标在不同密度下失去稳定性。

## 决策

1. `compact/standard/comfortable` 是 Table 专用显示偏好，只控制表格行高、表头与单元格留白等表格几何。
2. Table density 不传播为 ComponentSize，不改变筛选区、工具栏、分页、卡片、页面节奏或其他组合区域。
3. 表格行操作按钮、图标与 action overflow 菜单固定使用 `sm` recipe；切换表格密度时保持完全相同。
4. 筛选表单继续使用自身固定的紧凑尺寸；工具栏与分页使用各自默认尺寸。需要改变这些组件时显式配置 size，不借用 Table density。
5. 三级 `ComponentSize` 与三套 Renderer 的映射继续有效。它是组件显式尺寸能力，不是 Table density 的隐式全局缩放器。

## 结果

- 用户切换显示密度时只看到表格变紧凑或宽松，操作图标保持稳定。
- Workbench 不再维护 `density -> ComponentSize` 的通用传播函数，避免新组件被无意纳入表格偏好。
