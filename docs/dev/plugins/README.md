# 插件文档（Plugins）

> 每个产品与示例插件根目录的 `README.md` 是自身贡献、配置和使用方式的第一入口。本目录只保存需要跨模块说明的插件深度设计。

**注意**：插件机制本身的**系统设计**（统一插件定义/清单、宿主协议、契约字段、扩展点模型、生命周期、部署编排）不在这里，而在架构文档：

- 插件如何声明、如何通信、携带什么数据 → 《[插件契约与协议](../architecture/插件契约与协议.md)》
- 微内核、扩展点、四内核、通信、插件服务与编排 → 《[系统架构](../architecture/系统架构.md)》
- 为什么这么设计 → 《[决策记录 ADR](../decisions/README.md)》

## 文档归属

- 每个 `extensions/plugins/*` 与 `examples/plugins/*` 必须有本地 `README.md`，并与代码同次修改。
- 只有需要解释跨服务状态机、安全边界或复杂运维的插件，才在本目录增加深度设计。
- 深度设计只在 [文档地图](../00-index.md) 的“插件”小节登记；本文件不复制完整插件清单，避免形成第二真相源。

完整深度设计入口见[文档地图](../00-index.md#插件具体插件文档)。
